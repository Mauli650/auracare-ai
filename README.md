# AuraCare AI - Physical & Mental Health Companion 🩺🧠

**AuraCare AI** is an intelligent healthcare assistant designed for the **Hack for Humanity** hackathon. It bridges the gap between early physical health diagnostic guidance and empathetic mental health support.

## 🌟 Key Features
- **Mental Health Companion:** Analyzes user emotions/stress levels and provides personalized coping techniques.
- **Physical Health Assistant:** Preliminary symptom checker and medical report reader powered by generative AI.
- **Accessible Design:** Clean, simple, and empathetic interface for instant health support.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (React.js)
- **Backend:** Python (Flask / FastAPI)
- **AI Model:** Google Gemini API (Text & Multimodal Vision)
